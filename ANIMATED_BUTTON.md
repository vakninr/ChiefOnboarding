# Animated Button Web Component

A fully functional web component project has been set up in the `/frontend` directory.

## Quick Start

```bash
cd frontend
npm install
npm run build
npm run serve
```

Visit http://localhost:3000 to see the interactive demo.

## Integration

The component can be used in any HTML page:

```html
<script type="module" src="frontend/dist/animated-button.js"></script>
<animated-button text="Click me" variant="primary" size="medium"></animated-button>
```

See `/frontend/README.md` for detailed documentation.
